# Real-Time LFM Pulse Compression Core for Radar Digital Receivers

A high-performance, fixed-point **Linear Frequency Modulated (LFM) Pulse Compression System** designed for radar Digital Receivers (DRX), modeled in **MATLAB** and implemented in synthesizable **VHDL** targeted for a **Xilinx Kintex-7 FPGA**. 

The system captures an incoming **10 µs LFM radar pulse** spanning a **25–35 MHz chirp bandwidth**, executes digital downconversion (DDC) and I/Q baseband extraction, and uses a highly optimized matched filter stage to compress the echo into a **~0.1 µs narrow pulse**, achieving a target **Pulse Compression Ratio (PCR) of 100 (20 dB processing gain)**.

---

## 🛠️ Toolchain Infrastructure & DSP Environment

To maintain exact bit-true and cycle-accurate processing alignment across floating-point prototypes and physical FPGA hardware fabrics, the design was processed through a unified DSP toolchain flow:

*   **Algorithmic Modeling & Filter Design:** Structured inside **MATLAB**. Used to simulate floating-point chirp characteristics, design the 40-tap Chebyshev window low-pass filters, generate bit-true fixed-point matched filter coefficient arrays via time-reversal (`conj(fliplr(x))`), and verify processing gain boundaries.
*   **VHDL RTL Design & Simulation Testbench:** Architected, debugged, and cycle-accurately verified using **Vivado ILA**. The testing environment implements differential system clocks (`sys_clk_p`/`n` at 200 MHz) and behavioral test vectors to track internal signal flows.
*   **Logic Synthesis & IP Core Integration:** Compiled and synthesized inside **Xilinx Vivado System Edition** targeting a **Xilinx Kintex-7 FPGA** fabric. The design integrates high-throughput LogiCORE IP compiler blocks utilizing optimized internal DSP48 slices.

## 📐 DSP System Architecture & Signal Chain Mechanics

The digital receiver hardware pipelines incoming radar echo lines through four primary digital signal processing stages:

```text
       10 µs Chirp (25-35 MHz)
                 │
                 ▼
       [ 40 MHz ADC Sampling ]
                 │
                 ▼ (Aliased to 5-15 MHz Up-Chirp)
         ┌───────┴───────┐
         ▼ (I-Channel)   ▼ (Q-Channel)
    [ Mixer - I ]   [ Mixer - Q ]  ◄── Local Oscillator (10 MHz COS / SINE)
         │               │
         ▼ (5-15 MHz)    ▼ (5-15 MHz)
    [ LPF - Cosine ][ LPF - Sine ] ◄── 40-Tap Chebyshev Low-Pass Filter (fc = 8 MHz)
         │               │
         ▼ (Baseband I)  ▼ (Baseband Q)
    [ Matched Filter][ Matched Filter] ◄── Pulse Compression Cores (pc_real / pc_imag)
         │               │
         ▼               ▼
    fir_i_d_out     fir_q_d_out    ◄── ~0.1 µs Compressed Radar Echo Peak
```

### 1. Second-Subsampling Bandpass ADC Profile
*   The raw **25–35 MHz RF chirp** is undersampled by an external ADC clocking at **40 MHz**. 
*   By exploiting intentional spectral aliasing within the second Nyquist zone f_s = 40 MHz, the spectrum is naturally folded back and centered as a digitized intermediate frequency (IF) up-chirp sweeping cleanly from **5 MHz to 15 MHz**.

### 2. Digital Downconversion (DDC) & I/Q Demodulation
*   The digitized IF signal is split into dual orthogonal processing paths and mixed via complex multi-bit multipliers (`cmpy_0`) against a **10 MHz Local Oscillator** generated by an internal Direct Digital Synthesizer (`dds_compiler_1`).
*   Mixing the 5–15 MHz chirp with the 10 MHz LO translates the spectrum to baseband, producing difference components spanning from **-5 MHz to +5 MHz** alongside unwanted high-frequency sum components centered at 15–25 MHz.

### 3. 40-Tap Chebyshev Baseband Decimation Filtering
*   To wipe away out-of-band mixing products, the I and Q channels are passed into parallel **40-tap Chebyshev window FIR Low-Pass Filters** (`fir_compiler_1`) designed with a sharp cutoff frequency f_c of **8 MHz**.
*   This stage limits noise bandwidth, strips away sum components, and provides pristine baseband analytic signals ready for matched filtering.

### 4. Matched Filter Pulse Compression Core
*   The isolated baseband I/Q channels drive the final **Pulse Compression Filters** (`fir_compiler_0` and `fir_compiler_2`). The filter coefficients map out a time-reversed, complex-conjugated template of the reference baseband chirp.
*   As the 10 µs long pulse convolves with its matched template, energy coherent across the chirp window collapses into a sharp, narrow peak with an output width of τ ≈ 1/B = 1/10 MHz = 0.1 μs, driving massive radar target range-resolution improvements.

## ⚡ VHDL Top-Level Entity Hardware Implementation

The hardware top-level wrapper (`pulse_compression_top.vhd`) structures an automated Pulse Repetition Interval (PRI) timing machine that drives multi-stage LogiCORE processing cores:

### Core IP Component Layout
*   `clk_wiz_0` (Clock Wizard): Samples differential inputs (`sys_clk_p`/`n`) to synthesize a high-frequency internal **200 MHz core processing clock** (`clk_200M`).
*   `dds_compiler_0` (Chirp Generator): Simulates radar target reflections inside testbenches by generating a gated 10 µs burst up-chirp using a 32-bit phase accumulator.
*   `dds_compiler_1` (LO Generator): Generates continuous 200 MHz sample-synchronized 16-bit reference Cosine and Sine carrier tracks centered precisely at 10 MHz.
*   `cmpy_0` (Complex Multipliers): Directs high-speed multi-bit numeric matrix multiplications to execute I/Q downconversion without clipping errors.
*   `fir_compiler_1` (Low Pass Filters): Implements the 40-tap Chebyshev LPF structures utilizing internal symmetric systolic multiply-accumulate (MAC) structural cells.
*   `fir_compiler_0` / `fir_compiler_2` (Pulse Compression Cores): Implements the long-convolution matched filter arrays, mapping 64-bit precision output vectors (`fir_i_d_out`/`fir_q_d_out`) to preserve dynamic range.

### Master Timing Machine Processing Loop
Operating at 200 MHz (5 ns clock steps), the main sequential process controls a master counter loop bounded by a **100 µs PRI interval** (`PRI_MAX = 10000`):
1.  **Transmit Sync:** Pulses `pulse_out` high for exactly **10 µs** (`TON_MAX = 2000`) to signal the transmitter fire window.
2.  **ADC Strobe Stitling:** Restructures a 40 MHz clock domain inside the 200 MHz core fabric by pulsing a single clock cycle data-enable strobe (`sample_en`) once every **5 clock ticks** (`CLKS_PER_SAMPLE = 5`).
3.  **Adaptive Target Range Tracking:** Accepts a generic parameter (`G_DELAY_VAL`) that moves target return echo checks dynamically after the transmitter drops, allowing developers to simulate different physical target distances in simulation.
